前言 · 审核不是为了拦你

投稿审核不是拦截，是为了让内容能被更多人安全地看到。

我们的目标只有一个：你的话被看到，同时你也被保护住。

这份标准写清楚，是为了让你知道：

  • 什么一定会发
  • 什么一定不会发
  • 什么我们会和你商量着来
✨ 最重要的一句话：如果你不确定某条内容能不能发——先发出来。我们更愿意在审核后给你反馈，而不是你猜来猜去不敢发。

第一部分 · 绝不发布（红线）

以下内容无论什么原因、无论什么形式，一律不发布。这不是商量。

🔴 一、涉及违法与敏感

  1. 涉政内容：涉及国家、政府、公共事件的评论、传闻、立场
  2. 涉黄内容：露骨色情描写、性暗示图片、成人内容导流
  3. 涉毒 / 涉赌 / 涉暴内容：任何形式的描写或暗示
  4. 封建迷信、恐怖惊悚、血腥暴力的具体内容
  5. 违法交易、代写代发、有偿接单、卖课、卖服务

🔴 二、涉及可识别身份（最重要的红线）

以下任何信息出现在投稿里，我们会先做脱敏处理，处理不了就不发：

  1. 真实姓名、学校 + 具体班级、家庭住址、电话号码、微信号、QQ 号
  2. 能直接定位到人的照片（清晰人脸、可识别的校服 + 校徽、独特纹身/伤疤）
  3. 具体到时间地点的事件细节（"周三下午第三节课在某教室"这种组合信息）
  4. 他人的截图、聊天记录（未经对方同意）
  5. 任何"扒皮 / 人肉 / 挖身份"类内容——无论指向谁
📌 投稿人自查：如果投稿里出现别人能一眼认出来的信息，我们会打码。如果你希望被"完全截去"，请在投稿界面选"完全截去"档。

🔴 三、涉及他人隐私与名誉

  1. 未经当事人同意的爆料（"某某某其实……"）
  2. 恶意人身攻击、诅咒、辱骂特定个人
  3. 冒充他人投稿，或以他人身份发声
  4. 转发树洞内已有的投稿内容（含截图、二次传播）
  5. 涉及未成年人的不当内容（无论指向谁）

🔴 四、商业与导流

  1. 任何形式的广告、导流、拉群
  2. 卖货、卖服务、卖课、卖资源
  3. 引导私信 / 加微信 / 加 QQ 号
  4. 冒充管理或群主

第二部分 · 视情况处理（灰区）

以下内容可以发，但我们可能会和你商量。以下每一条都会附一句"我们的做法"。

🟡 一、校园 / 老师吐槽

处理方式：可以发，但建议加一句"仅供参考 / 仅为个人观点"，且不做指名道姓的具体指认。

我们理解"吐槽老师"是本地学生的核心情绪出口。但如果吐槽变成"点名道姓的公开审判"，投稿人也会陷入被动——保护投稿人的最好办法是保护投稿人自己。

💬 举例（参考话术）："某老师上周…… 这只是我个人经历，不知道具体情况如何，仅供参考"

🟡 二、恋爱情感类细节

处理方式：可以发，涉及双方身份的描述做模糊化（"他/她"、"某同学"）；涉及第三方具体信息（照片、聊天记录）会脱敏。

情感类是树洞的老本行，我们不会拦。但如果投稿里出现了能定位到具体人的信息，我们会先打码，处理不了再发。

🟡 三、家庭矛盾类

处理方式：可以发，涉及家人姓名/照片一律脱敏。若涉及家暴/虐待/严重伤害，走紧急通道（见第五部分）。

🟡 四、传闻 / 打听类

处理方式：可以发，但建议投稿人标注"听闻 / 想确认"，避免被解读为爆料。

"听说 XXX 是怎么回事？"这种打听帖可以发，但如果是"XXX 做了 XXX"这种断言，我们更倾向于请你改成疑问句。

🟡 五、争议话题（性别、校园事件等）

处理方式：可以发，但要求描述性、非立场性。避免"我觉得男生/女生都……"这种整体性评判。

树洞不是公共辩论场。你可以发你的感受，但请不要让别人的感受被你的感受替代。

🟡 六、求助 / 医疗 / 法律 / 心理专业问题

处理方式：可以发，但我们会在回复区提示专业资源（热线、渠道），并尽量不做诊断。

树洞不是心理咨询室，也不是法律援助。我们能做的是让你的问题被看见，然后指向专业的地方。

🟡 七、极端情绪表达（自伤 / 轻生倾向）

处理方式：会优先发布，同时私下联系投稿人做关怀跟进。

如果你正在经历这样的事，请把这份投稿当成一个求救信号。我们不会删你的内容，但会尝试联系你。同时，请务必拨打：12356 / 120 / 110。

🟡 八、长文 / 多段 / 图文混排

处理方式：可以发，但我们可能会分段发布或压缩排版以提升可读性。原稿的完整表达会保留。

第三部分 · 投稿建议（鼓励性条款）

这些不是必须，但会让你的投稿更顺畅地被看到。

✅ 关于匿名

  • 默认匿名强度建议选"涂抹"（比打码更彻底）
  • 涉及熟人圈的信息，建议直接选"完全截去"
  • 投稿前自查：如果朋友列表里有能对上号的人，请用最高档

✅ 关于吐槽

  • 涉及老师 / 同学 / 家人，建议加一句"仅供参考 / 仅为个人经历"
  • 避免使用具体姓名、班级、照片
  • 争议性话题尽量用描述性语言，不用整体性评判

✅ 关于求助

  • 说清楚"想问什么"比"发生了什么"更重要
  • 长文可分段，我们不会拒收长文

✅ 关于求助类内容（尤其是自伤 / 轻生）

  • 请同时告诉一位你信任的人（家人、朋友、老师）
  • 如果情况紧急，请直接拨打 12356 / 120 / 110
  • 树洞不是替代专业资源的场所

✅ 关于转载

  • 树洞内容不搬运、不截图、不传播到群外
  • 想分享某条内容给别人？请让对方自己进来
  • 二次传播是树洞最大的伤害来源

第四部分 · 审核流程

📋 常规流程

你投稿→ 24 小时内审核→ 发布 或 拒绝附说明→ 可申诉

📋 拒绝时你会收到什么

如果审核未通过，你会收到一条私信或群内回复：

关于 📌 #XXX 号投稿
未通过审核：违反《投稿审核标准》第 X 条
原因：[具体说明]
如需申诉，请私信管理，24 小时内回复。

为什么给说明？因为"沉默地吞掉投稿"是最伤人的审核方式。我们希望你知道错在哪里，而不是只知道被拒了。

📋 申诉流程

收到拒绝→ 24 小时内私信管理申诉→ 24 小时内复审→ 反馈结果

什么情况可以申诉？

  • 你认为审核判断有误
  • 你认为内容被误删（例如被误判为辱骂、被误判为爆料）
  • 你认为脱敏方式不合适
  • 任何你觉得不合理的地方

申诉的回复承诺：24 小时内必回；即使再次拒绝，也会附上第二次说明。

第五部分 · 紧急情况通道

以下情形会绕过常规审核，走加急流程：

🚨 一、涉及自伤 / 轻生倾向

  • 优先发布
  • 私下联系投稿人做关怀
  • 提示专业资源

🚨 二、涉及人身安全的求助

  • 优先发布
  • 提示 120 / 110 / 12356
  • 必要时通知投稿人所在地的同学/朋友

🚨 三、涉及未成年人保护

  • 内容会被脱敏到无法识别具体人
  • 必要时不上架，但会私下联系相关方

🚨 四、涉及紧急事件

  • 群内紧急事件（比如某人出事）会先核实再发布
  • 未经核实的紧急情况不发布，但会私下提醒知情者

第六部分 · 常见 Q&A

Q：什么是"人肉"或"扒皮"？

A：为了挖掘某个投稿者/被提及者的身份，通过信息拼凑、追问、截图比对、私下询问等方式识别其真实身份——无论目的是否"善意"。

Q：为什么我的吐槽被拒了？

A：可能是内容里出现了能直接定位到具体老师/同学的信息（如"高三某班某老师"）。请改用"某老师""某位老师"这类模糊表述。

Q：怎么判断是否涉及他人身份？

A：一个简单的自查——如果这条投稿里出现的信息组合起来，本地学生里能对应到某一个人，那就有风险。宁可多打码，不要少打码。

Q："仅供参考"这个建议是必须的吗？

A：不是必须。但如果你的内容可能被理解成"公开审判某人"，加这句话能同时保护你和被提及的人。

Q：审核要多久？

A：常规投稿 24 小时内反馈。紧急情况会加急。

Q：被拒了可以申诉吗？

A：可以，见第四部分。我们承诺 24 小时内必回。

Q：如果我发了违规内容会被怎么处理？

A：首次提醒 + 修改后发布；反复违规会限制投稿权限；触碰红线（人肉、爆料、泄露他人信息）会直接移出。

Q：我能匿名投稿吗？

A：可以，而且是默认。你甚至不需要告诉我们你是谁。

场景常见误删原因建议改法
吐槽老师指名道姓用"某老师""高三某位老师"

结语

树洞不完美，审核也不完美。我们更愿意在审核之后告诉你为什么，而不是审核之前让你猜。

如果这份标准里还有什么没覆盖的地方，告诉我们。这份文档会持续更新。
